# Assets de marca

Coloque aqui os arquivos de logo antes de começar a rascunhar no Paper — é o
que o rascunho vai usar, e depois o componente de logo do Remotion também.

```
/brand
  /links-ondas     # logos Links Amarelos + Ondas Amarelas (tema amarelo)
  /hyperlinks      # logo Hyperlinks (tema azul)
```

Formato preferido: **SVG**. PNG com fundo transparente resolve, mas escala pior
nas resoluções grandes (1080×1920 e 1456×1040).

Vale subir, se existirem:
- cada logo isolada;
- a versão **empilhada** das duas logos de `links-ondas` — o plano menciona que
  existe uma forma definida de empilhar; o gatilho de quando usar cada versão
  fica decidido junto com o design no Paper (seção 4 do plano);
- versão sobre fundo claro e sobre fundo escuro, se forem diferentes.

Nada aqui está referenciado em código ainda — a implementação do componente de
logo vem depois da exploração visual.
